# Practice Problems

`PDP-Practice-Problem-Bank.py` is a combined, sequentially-numbered set of 38 blank-stub Python practice problems (student fills in each function body), general PDP practice rather than mapped to one specific learning outcome — spanning arithmetic, string manipulation, pattern printing, boolean logic, and small utility functions built as static methods on themed classes.

It was assembled from several originally-separate problem sets that turned out to be one continuous, arbitrarily-split problem sequence — confirmed by matching function counts against the "Problem N" numbering that already appeared in the later problems (23 onward) and finding it lined up exactly (7 + 5 + 5 + 5 = 22, then Problem 23 picks up cleanly). Problems 1-22 didn't carry numbering in their source docstrings and were numbered here to make the whole thing one continuous bank.

Sections, in order:
- **A: Arithmetic Basics (1-7)** — first programs, sums, division, operator precedence, swapping, multi-operand arithmetic
- **B: Patterns, Conversions and Strings (8-22)** — multiplication tables, averages, string patterns, temperature conversion, string indexing/manipulation, conditional logic on number ranges
- **C: String & Number Utilities (23-38)** — case conversion, longest word, primes, digit sums, file size, hex-to-decimal, array operations, range/multiple checks, most-frequent-element, palindrome check — grouped into the three themed classes (`StringAndNumberExercises`, `StringAndArrayExercises`, `NumberAndStringChecks`) the source files already used

A messy in-progress duplicate of problems 1-7, and a stray C#-language scrap with no home in a Python-only PDP course, were excluded when this bank was assembled.
