# Enrichment

Content that's related to the MIT/PDP curriculum in spirit — built with the same tools, useful to the same students — but goes beyond what any numbered learning outcome in either module descriptor actually requires. Unlike [`../../OtherCourses/`](../../OtherCourses/) (which is a wholly different course), this folder is squarely adjacent to MIT/PDP; it's just optional.

This mirrors how the `mathematics` repo already treats its own beyond-syllabus worksheets (matrices, eigenvalues, Markov chains, binomial/Poisson distributions) — present and useful, but consciously not counted as filling any MIT/PDP gap.

| File | Covers | Beyond-syllabus because |
|---|---|---|
| `Taylor-Series-Exponential-Sine-Cosine.ipynb` | Coding `e^x`, `sin(x)`, `cos(x)` from their Taylor series definitions, truncated by term count or convergence threshold | MIT Section 3 (functions/calculus) stops at LO 3.7 (chain rule); Taylor/Maclaurin series and Euler's formula are never a numbered outcome |

See [`../../planning/2026-08-01-upload-manifest.md`](../../planning/2026-08-01-upload-manifest.md) for provenance, and the file's own header cell for how it pairs with `mathematics/worksheet_04d_transcendental_series.md`.
