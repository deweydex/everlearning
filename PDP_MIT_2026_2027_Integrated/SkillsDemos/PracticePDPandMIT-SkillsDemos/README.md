# Practice PDP Skills Demos

A third track alongside `BoringPDPandMIT-SkillsDemos/` and `FunPDPandMIT-SkillsDemos/`, sourced from a 2026-08-01 upload of older skills-demo drafts. Unlike those two tracks, these are **not a matched pair covering the same content** — they're two different-themed practice skills demos, plus one worked solution to a third, unrelated Skills Demo 2 design. Useful as extra formative practice, or as alternate assessment ideas for a future year.

| File | Skills Demo | Weight | Theme | Status |
|---|---|---|---|---|
| `NB1_PDP_SD1_List-Operations-Practice.ipynb` | SD1 | 30% | `same_length`, `list_addition`, "gradeschool" digit-wise list addition, a bonus subtraction challenge | Blank student template |
| `NB2_PDP_SD2_Card-Game-Practice.ipynb` | SD2 | 40% | Building a card deck, a shuffle/pick function, a user-guesses-the-card game, a computer-guesses-the-card game with higher/lower logic | Blank student template (some starter code included, with deliberately buggy `user_picks_a_card` for students to debug) |
| `SOLUTION_PDP_SD2_Word-Length-Language-Classifier.py` | SD2 (alternate design) | 40% | Analysing word-length statistics across texts from Dewey (English), Montessori (Italian), and Freire (Portuguese) to build a language classifier | **Complete worked solution**, not a student template — useful as a model answer / marking-scheme exemplar |

Note the Skills Demo 2 mismatch: `NB2` and the `SOLUTION_` file are two entirely different SD2 designs (card game vs. language classifier), not two versions of the same assignment. Don't assume the solution file is an answer key for `NB2` — it isn't.

## Relationship to the other SkillsDemos tracks

`BoringPDPandMIT-SkillsDemos/` and `FunPDPandMIT-SkillsDemos/` remain the primary, currently-used skills demonstrations — see [`../../../planning/repo-inventory.md`](../../../planning/repo-inventory.md) for how those two compare. This folder is a preserved bank of prior-year/alternate material, not a replacement for either.
