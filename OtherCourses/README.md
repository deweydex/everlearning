# Other Courses

This folder is **not** part of the QQI Level 5 MIT/PDP curriculum that lives under [`PDP_MIT_2026_2027_Integrated/`](../PDP_MIT_2026_2027_Integrated/). It exists so that material uploaded alongside PDP/MIT files (from a 2026-08-01 batch of skills-demo drafts and a `python.zip`) doesn't get lost or, worse, accidentally mixed into the QQI course content it was found next to.

Everything here belongs to other courses/levels this repo's owner teaches. See [`../planning/2026-08-01-upload-manifest.md`](../planning/2026-08-01-upload-manifest.md) for the full breakdown of where every file from that upload ended up and why.

## What's here

- **[`Markov-Chains-and-Text-Generation/`](./Markov-Chains-and-Text-Generation/)** — a 10-week advanced/extracurricular course: random walks → transition matrices → a `MarkovChain` class → character/word-level text generation → final projects (weather prediction, stock simulation, a text generator). Far beyond QQI Level 5 MIT/PDP scope (matrices, class design, NLP-style generation, perplexity).
- **[`Computer-Graphics-Algorithms/`](./Computer-Graphics-Algorithms/)** — Bresenham's line algorithm and the midpoint circle algorithm (rasterization). Filenames ("Part 1B", "Part 2B") suggest this was part of a larger sequence whose "Part 1A"/"Part 2A" counterparts weren't in this upload.
- **[`Neural-Network-Pruning/`](./Neural-Network-Pruning/)** — a structured-pruning code snippet for Keras/TensorFlow dense models. Graduate-level ML content, and it's a fragment (assumes an existing trained model in scope), not a standalone notebook.

## Why keep it at all, rather than just describing it in the manifest?

These looked like real, usable teaching material for whatever course they belong to — worth preserving in git history rather than only existing in an uploaded zip that isn't itself under version control anywhere. If none of this is wanted here, it's self-contained and safe to delete as a whole folder.
