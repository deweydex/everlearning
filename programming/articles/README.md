# Programming and Design Principles 5N2927

## What this course does

A first programming course in Python that keeps machine learning in view, so that the examples learners write are the kinds of thing a data or ML program does. Twelve tutorials carry the module's learning outcomes and cite them inline. Practice notebooks go deeper on loops, lists and comprehensions. A three-notebook bridge into object-oriented programming serves Fundamentals of Object-Oriented Programming 5N0541, and the assessments folder holds the skills demonstrations and mock exam.

## What you will learn

How to work in a notebook. Where programming languages came from. Planning with pseudocode and flowcharts. Variables, types and operators; loops; lists and comprehensions; functions and scope; errors, testing and debugging. The math and random modules, NumPy, Matplotlib, and classes and objects.

## What we expect you to know already

Nothing about programming.

## The notebooks, in order

0. `New_00_Your_Questions` — the learner's own situations, written down before the first lesson and returned to at the end.

Tutorials 0 to 12 in `Tutorials`.

`Practice` has loops (with Tutorial 5), lists and matrices and list comprehensions (with Tutorial 6), and an enrichment notebook on recursion (with Tutorials 2 and 7).

`Object-Oriented-Programming` and, as a second route through the same ground, a Worked Project building Constant, Linear, Quadratic and general Polynomial classes up to inheritance and polymorphism continues from Tutorial 12: an interactive map, the Hitchhiker's Guide, shapes and a game map, then the FOOP exam as a Python file with its sample answers.

`Assessments` has Skills Demonstration 1, Skills Demonstration 2, a teacher version of the alternative Drawing-with-Arrays demonstration, and the mock exam with its answer key. `Alternates` has the ocean-themed loops and pirate-themed lists notebooks, the 2025 Skills Demo 1, a colleague's prefinal Skills Demo 2, and a short three-function exercise.

## Notes for teachers

Tutorials 0 to 8 are the assessed core; 9 to 12 are the library and OOP tail that the AI and ML Foundations course relies on. The Practice notebooks are alternative framings of one lesson rather than a sequence, so pick per group.
