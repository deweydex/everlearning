# everlearning

Notebook tutorials, skills demos and planning for two Irish QQI Level 5 modules taught together: Maths for Information Technology (5N18396) and Programming and Design Principles (5N2927). Everything sits under `PDP_MIT_2026_2027_Integrated/`; `OtherCourses/` holds three shorter courses on graphics algorithms, Markov chains and neural-network pruning.

## Status: archive of sources

The seventeen tutorials here were converted, one for one, into the *Programming and Maths, Integrated* series in the `dewlab` repository, which is now where tutorials are written, versioned and published. The practice problem bank gave dewlab's practice pages their questions. Nothing new is written here; if a dewlab tutorial needs something that only exists in this repository (a skills demo, an enrichment notebook, one of the other courses), it is taken from here and reworked there.

`planning/` holds the inventory and gap analysis from August 2026, when this repository was still the working home, and the consolidation analysis from September 2026 that moved the centre to dewlab: `planning/2026-09-03-repo-consolidation-analysis.md`.
