# Database Methods 5N0783

## What this course does

Learners meet data as tables from the first session and learn two ways of asking questions of it: SQL, through SQLite, and pandas, through Python. The two are taught side by side on purpose, so that a query in one language can always be checked against the other. The course ends with a project in which learners build a small database with a form to add to it, and a practical exam in which they work with an unfamiliar database under time.

## What you will learn

How to create a SQLite database, define tables, insert rows and query them. How to load, filter, group and summarise data in pandas and draw it with Matplotlib. How the two approaches correspond, clause by clause. How to move data between pandas and SQLite. How to build interactive widgets and a form that writes to the database.

## What we expect you to know already

Python variables, lists, loops and functions. No SQL and no pandas.
