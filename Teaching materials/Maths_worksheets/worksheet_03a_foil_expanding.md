## Part A: The FOIL Method — Basic Mechanics (12 problems)

**FOIL** stands for **F**irst, **O**uter, **I**nner, **L**ast — a method for multiplying two binomials.

**Example:** $(x + 3)(x + 2)$

```
First:  x · x = x²
Outer:  x · 2 = 2x
Inner:  3 · x = 3x
Last:   3 · 2 = 6

Combine: x² + 2x + 3x + 6 = x² + 5x + 6
```

## Part E: Patterns Worth Memorizing (8 problems)

These patterns appear so often that recognizing them instantly saves time.

### Pattern 1: Perfect Square Trinomials

$$\boxed{(a + b)^2 = a^2 + 2ab + b^2}$$

$$\boxed{(a - b)^2 = a^2 - 2ab + b^2}$$

*The middle term is always **twice** the product of the two terms.*

### Pattern 2: Difference of Squares

$$\boxed{(a + b)(a - b) = a^2 - b^2}$$

*The middle terms cancel out, leaving only the difference of squares.*

## Part G: Beyond Two Terms (8 problems)

For multiplying larger expressions, we distribute systematically.

**Example:** $(x + 2)(x^2 + 3x + 1)$

```
Distribute x:   x·x² + x·3x + x·1    = x³ + 3x² + x
Distribute 2:   2·x² + 2·3x + 2·1    = 2x² + 6x + 2
Combine:        x³ + 3x² + 2x² + x + 6x + 2 = x³ + 5x² + 7x + 2
```

**Expand completely:**

**64.** $(p - 2)(p^2 + 4p + 1)$
