# Markov Chains and Text Generation — 10-Week Course

An advanced/extracurricular Python course, unrelated to the QQI MIT/PDP module descriptors. It's framed as one continuous build: "by Week 10 you'll have created programs that generate realistic text, predict tomorrow's weather, and simulate random processes."

| File | Covers |
|---|---|
| `Week00_Python-Foundations.ipynb` | Print/variables/loops/lists/functions, a text-analyzer mini-project — the one week that *does* overlap QQI-level basics |
| `Week01-02_Probability-and-Random-Walks.ipynb` | Random walks, counting state transitions, converting counts to probabilities, a weather-prediction game |
| `Week03-04_Matrices-and-Markov-Chains.ipynb` | Transition matrices, matrix multiplication, steady-state discovery, matrix powers |
| `Week05-06_Building-a-Markov-Chain-Class.ipynb` | A full `MarkovChain` class, higher-order chains, a stock-market simulation, a customer-journey example |
| `Week07-08_Text-Generation-with-Markov-Chains.ipynb` | Character- and word-level text generation, training on real corpora, perplexity, author style transfer |
| `Week09-10_Final-Projects-and-Applications.ipynb` | Capstone projects (weather forecaster, text generator, stock simulator, game AI, or music generator) with an assessment rubric |

**Why it's not in the QQI curriculum:** matrix operations, custom class design, and Markov-chain text generation are well beyond the MIT (5N18396) and PDP (5N2927) Level 5 module descriptors — this reads as a standalone enrichment or a different, more advanced module entirely. Week 0 is the only week whose content (basic Python fundamentals) already overlaps what QQI PDP covers, and it's covered there in more depth already.

Original filenames were `week0_notebook.py` … `week9_10_notebook.py` — they were valid Jupyter notebook JSON saved with a `.py` extension; renamed to `.ipynb` here to match their actual format, content otherwise unchanged.
